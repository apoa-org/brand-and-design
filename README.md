# APOA Brand and Design

Public source for APOA brand identity, UI guidance, event visuals and social media design assets.

## Contents

- `brand-guidelines/` — logo, colour, typography and usage guidance
- `logos/` — approved source and export formats
- `ui/` — interface patterns and approved UI references
- `events/` — reusable event visual assets
- `media/` — WeChat Channels and social media templates
- `releases/` — approved design package release notes

Use versioned filenames such as `logo-horizontal-v1.1.svg`; avoid names such as `logo-final-new.png`.
