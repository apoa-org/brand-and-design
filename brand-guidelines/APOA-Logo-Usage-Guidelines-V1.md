# APOA Logo Usage Guidelines V1

**Australian Property Owners Alliance (APOA)**  
**澳洲房主联盟**  
状态：**Approved baseline · 2026-10-27 已确认**  
归档建议：`APOA-Brand-Kit/02-Logo/APOA-Logo-Usage-Guidelines-V1.md`

> 本文件规定 APOA 标志的选用与基本使用方式。以 `02-Logo/02-Master/APOA-Logo-Master.af` 中的原始矢量设计为唯一视觉母版；本文件不替代设计源文件。

## 1. 基本原则

1. **优先使用已批准的 Logo 资产**；不要重新手绘、AI 近似生成或从宣传图片中截取 Logo。
2. 保持原始房屋轮廓、双房屋叠放关系、四个圆点、APOA 字形与各版排版比例。
3. **彩色 Logo 的四个圆点是实心白色图形**，不是透明挖空；在彩色背景或印刷品上也须保持其白色视觉效果。
4. Logo **只能等比例缩放**，不得横向或纵向拉伸、旋转、透视变形，亦不得随意改变颜色和线宽。
5. 依场景选择既有版本，不为每个活动重新开发一个“特殊 Logo”。

## 2. 九个既有版本及选用场景

| Master 画板 | 名称 | 推荐场景 | 注意事项 |
|---|---|---|---|
| `01-Primary Logo` | 主标志 | 官网主要品牌展示、正式封面、品牌介绍 | 彩色双房屋 + 原始 APOA 字形；默认优先使用 |
| `02-Chinese Logo` | 中文标志 | 中文为主、需要突出中文名称的物料 | 中文名称统一为「澳洲房主联盟」 |
| `03-Bilingual Logo` | 中英双语标志 | 中英文双语介绍、联合活动物料 | 不单独重排两行文字 |
| `04-Symbol Only` | 纯图形标志 | 已有 APOA 名称的区域、社媒头像、较小图形位置 | 不应成为首次对外介绍时唯一的品牌识别信息 |
| `05-Wordmark` | APOA 字标 | 横幅局部、空间有限但已建立品牌识别的场合 | 使用原始字形，不以普通字体输入“APOA”代替 |
| `06-Website Lockup` | 网站组合标志 | 明确需要引导访问网站的宣传物料 | `apoa.org.au` 为组合的一部分；不要临时换字体 |
| `07-Mono Black` | 黑色单色版 | 黑白文件、部分单色印刷、深色不适用的浅底物料 | 保持母版中各图形的实心／轮廓关系；白色元素与材料、印刷工艺需核对 |
| `08-Reverse White` | 白色反白版 | 深色背景、深色照片上的品牌展示 | 输出时去掉仅用于预览的黑色背景层；确认线条及局部镂空可辨识 |
| `09-Horizontal Logo` | 横向组合标志 | 网站页眉、PPT 内页、窄横幅、页脚 | 使用已排好的图标与字标相对位置，不自行重新组合 |

**默认选择规则：**空间充足、首次展示品牌时用 `01`；长横向区域用 `09`；深底用 `08`；只允许单色输出时优先考虑 `07`。中文／双语名称需要明显呈现时选择 `02` 或 `03`。

## 3. 颜色

品牌基础色以 `03-Colors-Typography/APOA-Brand-Colors-V1.md` 为准：

| 颜色 | HEX（sRGB） |
|---|---|
| APOA Navy | `#2B2C55` |
| APOA Red | `#DA2D2A` |
| APOA Black | `#000000` |
| APOA White | `#FFFFFF` |

- 彩色 Logo 的红、蓝及实心白色圆点保持不变。
- 屏幕与普通印刷允许合理色差，优先选择能使 RGB / CMYK 视觉效果接近的输出方式；**不强制 Pantone 专色**。
- 黑白单色版本与反白版本使用各自的既有母版，不通过直接将彩色版“滤镜变黑／变白”代替。
- CMYK 数值暂不统一锁定；按实际材料和供应商流程转换，必要时查看实物样张。

## 4. 背景与识别

- **白色或浅色纯背景**：优先选彩色 `01`、`02`、`03` 或 `09`。
- **深色背景**：优先选 `08-Reverse White`，必要时为 Logo 提供独立的深色纯色区域。
- **复杂照片背景**：避免把 Logo 放在纹理杂乱、明暗变化大的位置；可改用留白区域或加单色底板。
- **深蓝／红色底上的彩色 Logo**：谨慎使用，避免房屋轮廓与底色混在一起；不要为适配背景随意改动 Logo 色值。

## 5. 留白与最小尺寸（待量测确认）

**已确认：**Logo 四周应保留足够空间，避免贴近文字、边框、照片主体或页面边缘。

**尚未确认具体数值：**

- `01` 主标志、`09` 横向版和 `04` 图形版的最小使用尺寸；
- 各版本四周的最小保护区；
- 适用于屏幕／印刷的最小字高和线宽。

**临时执行规则：**以实际可辨识为准，缩小后如果圆点、细线、中文文字或网址已经不清晰，就换用更简洁的版本或增大尺寸。**不要把临时经验写成已批准的固定毫米／像素指标。**

## 6. 各类物料建议

| 物料 | 优先版本 | 补充原则 |
|---|---|---|
| 官网页眉 | `09-Horizontal Logo` | 小屏幕可经测试后选 `04-Symbol Only` |
| PPT 封面 | `01-Primary Logo` | 以视觉平衡为主，保持比例 |
| PPT 内页／页脚 | `09-Horizontal Logo` | 不抢占内容空间 |
| 社媒头像 | `04-Symbol Only` | 注意圆形裁切安全区 |
| 中文宣传海报 | `02-Chinese Logo` 或 `03-Bilingual Logo` | 视文字和版面需要选择 |
| 活动横幅／旗帜 | `01`、`03` 或 `09` | 先看远距离识别度与实际印制尺寸 |
| 白帽、白 T 恤、纸袋 | 彩色 Logo 或经测试的单色版 | 圆点要保持白色；注意不同材料工艺 |
| 深色服装／深色底 | `08-Reverse White` | 先核对印花细线、圆点与材料对比 |

## 7. 禁止用法

- 不拉伸、压扁、倾斜或旋转。
- 不改变房屋重叠关系、轮廓、圆点数量与圆点填充方式。
- 不将彩色版本的四个白色实心圆点改为透明孔洞。
- 不用系统字体重新键入 APOA 来取代原字标。
- 不为某次活动任意改成其他红蓝色、渐变、阴影、描边或发光效果。
- 不将低分辨率截屏用于大幅面输出。
- 不在色彩与对比不足的背景上强行使用彩色 Logo。
- 不未经确认自行挪动图形、中文名、网址和 APOA 字标之间的位置。

## 8. 母版、导出与管理

- **唯一矢量母版：**`02-Logo/02-Master/APOA-Logo-Master.af`。
- **交付：**从母版对应画板导出 SVG（网站／矢量应用）、PNG（透明背景／常见办公软件）、PDF（印刷交付，按供应商要求）。
- **文字：**印刷或跨系统交付时使用已经转曲的输出；母版中保留可编辑文字副本以便维护。
- **透明：**导出 `08-Reverse White` 时关闭黑色预览背景；逐项检查透明、镂空与白色图形是否符合母版设计。
- **版本管理：**旧活动和已印制物料不追溯修改；新的正式物料使用目前确认的名称和 Logo 资产。
- **来源：**Logo 用原始设计文件，不用 AI 重新绘制近似图形。
