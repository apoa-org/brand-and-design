# APOA Brand Guidelines

This directory holds visual branding standards; the organizational narrative comes from the [approved APOA Organization Master 2027](https://github.com/apoa-org/organization-handbook/blob/main/about/APOA-Organization-Master-2027.md).

**Current content baseline:** Australian Property Owners Alliance (APOA); 连接 · 分享 · 改变 / Connect · Share · Make a Difference. New Chinese-facing materials gradually use 澳洲房主联盟; leave historical materials unchanged.
