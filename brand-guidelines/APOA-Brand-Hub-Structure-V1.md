## 三、发布与管理规则

1. **状态不冒充成果。** 未完成一律显示「准备中」，不放空下载按钮，也不展示仿真成品或假预览。
2. **内容批准在前，模板发布在后。** 机构介绍与 Q&A 等讨论稿，在团队正式通过之前，不作为已批准对外介绍发布。机构事实、宗旨、愿景以 [APOA 机构介绍正式母本](https://github.com/apoa-org/organization-handbook/blob/main/about/APOA-Organization-Master-2027.md) 为准。
3. **单一下载入口。** 应用页说明用途和状态，完成的文件统一进入 `/downloads/`，预览与下载链接需实际可用。
4. **基础与应用分离。** `/manual/` 保留基础品牌规范；随着实际设计完成，逐步形成 `Brand Applications Manual`，而不是重新修改基础规则。
5. **历史物料保护。** 旧活动、已制作宣传品和既有历史名称不追溯修改；新做或补货时逐步使用新标准。
6. **版本可追溯。** 所有正式新增素材须注明用途、格式、状态、版本及来源，保留 GitHub 修改历史；不覆盖历史 Logo 母版。
7. **普通志愿者使用方便。** 网页先看场景、预览和说明，再一键下载；不要求用户懂 GitHub。

本文件仅确定目录与发布原则，不构成尚未制作的宣传物料已完成或已获批准的声明。
