# APOA Brand Colors V1

**Australian Property Owners Alliance (APOA) · 澳洲房主联盟**  
**Status:** Approved baseline · 2026-10-26  
**Scope:** Logo, presentation templates, Canva assets, future website design system

## 1. Primary brand colours / 品牌基础色

| Name / 名称 | HEX (sRGB) | RGB | Usage / 用途 |
|---|---|---|---|
| APOA Navy / 深蓝 | `#2B2C55` | `43, 44, 85` | Logo blue house; principal brand colour |
| APOA Red / 红 | `#DA2D2A` | `218, 45, 42` | Logo red house; accents |
| APOA Black / 黑 | `#000000` | `0, 0, 0` | Black logo lettering and mono-black variant |
| APOA White / 白 | `#FFFFFF` | `255, 255, 255` | White circles and reverse-white elements |

These values are the **approved digital colour values**. Do not change the existing red/blue logo colours simply for aesthetic reasons.

## 2. Printing principle / 印刷原则

- Prioritise colours that remain **visually close** between digital RGB and ordinary CMYK printing.
- Reasonable variation between screen and printed materials is acceptable; exact colour matching is not required.
- Pantone spot colours are not mandatory.
- **No universal CMYK values are approved yet.** Convert for the printer's equipment, material and profile; request a simple proof if needed.
- For fine black text and lines, printers may specify single-black ink (`K100`). For large black areas, follow the printer's recommendation. This is a print-production setting, not a change to the brand's RGB colour.
- The four dots in the standard **colour logo are solid white (`#FFFFFF`) shapes**, not transparent knockouts. On non-white material, confirm with the supplier how to produce white (for example white ink/underbase).

## 3. File and application rules / 文件与使用

- Keep `APOA-Logo-Master.af` as the editable logo source file.
- Use this palette for PPT and Canva templates and as the starting palette for the upcoming web UI design system.
- Do not automatically treat these four colours as the full website accessibility palette. Text, button and background combinations require separate contrast and usability checks.
- Record future **approved** changes with a new version, rather than silently replacing this baseline.

## 4. Maintenance / 规范管理

- 不另外维护 Affinity Palette；此 Markdown 为官方色值记录。
- 本规范纳入 APOA Brand Manual V1 基础版，后续更改须版本化。
- 历史物料不追溯修改。
