## 1. 名称与品牌表达

- **英文全称：** Australian Property Owners Alliance (APOA)。
- **简称：** APOA。
- **新制作中文物料：** 逐步使用「澳洲房主联盟」，常见组合为「APOA 澳洲房主联盟」。
- **历史物料：** 已出版文章、旧活动、印刷品和社群历史称谓不追溯替换。
- **品牌表达：** 连接 · 分享 · 改变 / Connect · Share · Make a Difference。
- **官网：** https://apoa.org.au/。

品牌命名与网站过渡详情参见 [现行过渡规则](BRAND-NAMING-WEBSITE-TRANSITION-2026-10-12.md)。法律与组织事实以注册资料和机构母本为准。

## 2. 九种 Logo 版本

唯一可编辑视觉母版为设计者确认的 `APOA-Logo-Master.af`，包含九个独立画板；九页 PDF 为对应画板的视觉参考。

| 编号 | 版本 | 主要使用场景 |
|---|---|---|
| 01 | Primary Logo / 主标志 | 正式封面、组织品牌展示 |
| 02 | Chinese Logo / 中文版 | 中文传播 |
| 03 | Bilingual Logo / 双语版 | 中英文并列展示 |
| 04 | Symbol Only / 图形版 | 头像、小区域（上下文已有 APOA 名称时） |
| 05 | Wordmark / APOA 字标 | 已有品牌识别、空间有限的位置 |
| 06 | Website Lockup / 网站组合 | 需要突出 `apoa.org.au` 的物料 |
| 07 | Mono Black / 单黑版 | 浅底黑白输出、适当单色印刷 |
| 08 | Reverse White / 反白版 | 深色背景；导出时关闭预览黑底 |
| 09 | Horizontal Logo / 横向版 | 网站页眉、PPT 内页、横向区域 |

**关键规则：** 保持两间房屋的原始轮廓、重叠关系、四个圆点、APOA 原始字形和组合比例；不得拉伸、改色、重绘或用 AI 近似生成替代。**彩色 Logo 的四个圆点始终为白色实心形状，不是透明挖空。** 单黑与反白版采用各自的专门画板，不靠滤镜直接转换彩色版。

在留白、最小尺寸尚未测量前，以清晰可辨识为临时准则，不宣称已批准具体毫米／像素值。详见 [APOA Logo Usage Guidelines V1](APOA-Logo-Usage-Guidelines-V1.md)。

## 3. 基础色

| 名称 | sRGB / HEX | RGB |
|---|---|---|
| APOA Navy 深蓝 | `#2B2C55` | 43, 44, 85 |
| APOA Red 红 | `#DA2D2A` | 218, 45, 42 |
| APOA Black 黑 | `#000000` | 0, 0, 0 |
| APOA White 白 | `#FFFFFF` | 255, 255, 255 |

屏幕与常规 CMYK 印刷以**视觉接近、易于重复**为原则：允许合理色差、不强制 Pantone 专色、不预设通用 CMYK 数值；实际印刷依材料与供应商配置调整，必要时简单打样。非白材料的白色图案需与供应商确认白墨或底白处理。**不另行管理 Affinity Palette**，Markdown 色值文件是统一文字记录。

详见 [APOA Brand Colors V1](APOA-Brand-Colors-V1.md)。

## 4. 字体

- **Logo 专用字形：** APOA 英文保留原始固定字形；中文「澳洲房主联盟」使用已确认的苹方-简中黑体转曲字形。不得以 Arial 重新输入 Logo。
- **日常英文：** Arial 优先。
- **日常中文：** macOS 优先苹方-简；Windows 优先微软雅黑或系统默认无衬线字体。
- **网站与移动端：** 系统字体栈优先，具体 UI 样式在网站设计阶段测试。
- **PPT / Word：** 已确认的字号为推荐范围，不是每种介质必须强制一致的尺寸。
- **协作要求：** 不要求志愿者另外购买或安装字体。

详见 [APOA Typography V1](APOA-Typography-V1.md)。

## 5. 基础使用和输出

- 优先选用九个标准 Logo 中适合场景的版本，而不是另外拼接或修改形状。
- 浅色背景优先用彩色版，深色背景优先用反白版；复杂照片背景须保证识别度。
- 网站和办公文档使用经核对的 SVG、PNG；印刷按供应商要求交付适合的 PDF／矢量格式。
- 保留设计源文件和可编辑正文；Logo 导出应核对透明、白色圆点、细线和转曲字体。
- 已完成的 PPT V1 可作为首个应用模板，但不代表其他宣传品设计已经完成。
- 已有纸袋、旗帜、帽子、工作服等**不必重新制作**；新设计或补货时逐步统一。
