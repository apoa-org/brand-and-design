# APOA UI

UI patterns, components, wireframes and approved design references will be catalogued here.

- Organization identity, values and user-facing tone follow the [approved APOA Organization Master 2027](https://github.com/apoa-org/organization-handbook/blob/main/about/APOA-Organization-Master-2027.md).
- A future unified UI Design System should include login, registration, payments and event registration, including loading, success, error, handoff and next-step states in Chinese and English.
- This is a planning reference only: no design-system release or website implementation is authorized by this README.
